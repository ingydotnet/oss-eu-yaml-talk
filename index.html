Introducing YAMLScript* Aka YS (wise)* YS is dynamic transform language for YAML* Also a very complete programming language* All YS is 100% valid YAML* Existing YAML files evaluate as expected> in-1 ys$ <<<'say: "Hello, $(ENV.USER)!"' ys - -J$ <<<$'!ys-0\nsay: "Hello, $(ENV.USER)!"' ys -$ ys -e 'say: "Hello, $(ENV.USER)!"'* A simple YS program$ vim hello.ys$ ys hello.ys
How YS Works* YS compiles to Clojure code* Then it is evaluated$ ys -c hello.ys# Normal YAML data is still code:$ vim normal-data.yaml$ ys -c normal-data.yaml$ ys -J normal-data.yaml# !ys-0 tag makes it dynamic:$ vim -O dynamic-data.yaml normal-data.yaml$ ys -c dynamic-data.yaml$ ys -J dynamic-data.yaml

Introducing YAML Family Plugins* The rest of this talk is about the YAML Family Plugins* Some are implemented already, some are being planned* Plugins can be (and are!) written in Go, Glojure & YAMLScript* Compiled to Go libraries for go-yaml and Go programs* Compiled to shared libraries for YAMLStar* A Plugin is like a complex Option* Can be highly configurable* Deep reach into go-yaml & YAMLStar subsystems
The YAML Family Plugin APIs* YAML-Parser - replace the entire parser stage* Standardize on YAML event structs* Performance, correctness, capabilities* Many YAML parsers exist and can be made pluggable* YAML-Rules - custom loading and dumping for YAML* Make your own YAML DSLs* Custom tag resolution, construction and roundtripping* Comment-Model - loading, dumping, roundtripping comments* YAML was designed to ignore comments. Sanity.* Several YAML frameworks support loading comments* All work differently. Plugins let you choose.* Tab-Indent - use tabs instead of space for YAML indentation* Biggest complaint about YAML overall* YAML team tried hard for tabs in early years* Now available to try using plugins
The YAML Family Plugin APIs* YAML-Schema - apply constraints at load time* Use schema language of your choice* Works with YAMLSchema of course* YAML-Format - custom, per node formatting* Full control over how each node or node type gets formatted* Function-Tags - !shuffle shuffle a sequence* Map tags to custom functions / libraries* Works best with YAML-Rules (implicit tagging)* Create your own mini-YAMLScript* Meta-Tag - top level tag declaring full intent* Associate a YAML to its Rules/Schema/Formatting etc* A tag that declares how YAML is expected to be processed* URLs work well - !kubernetes.io/yaml/service/v1* Optional. Application determines how tag is used
The YAML Family Plugin APIs* Error-Format - customize YAML error formatting* Allows YAML to change without breaking user expectations* I18N-Translate - YAML keys in any language* Translates to canonical language* Canonical langauge matches schema* JSON-Comments - support JSONC C-style comments in YAML* Support loading YAML with /* comment */ and // comment* Usefulness is Unknown!

YAML-Parser Plugin: "reference"* Parsing is the first stage in the YAML Load stack* Different parsers make different tradeoffs* Compatibility, correctness, performance* Plugins let applications choose the parser* Without changing the rest of the Load stack
Demo of the YAML-Parser Plugin: "reference"* https://play.yaml.com/?show=gdhflLnJPpxHUrsS#OiBmb28=The native go-yaml parser:$ <<<': foo' go-yaml -YBuild go-yaml with the YAML reference parser:> make -C go-yaml cli PLUGIN=parser=reference$ <<<': foo' go-yaml -YYAMLStar ships with both parsers:$ <<<': foo' yaml --plugin=parser=go-yaml -Y$ <<<': foo' yaml --plugin=parser=reference -YSame load stack, different parser* The reference parser follows the YAML 1.2 grammar* go-yaml remains the native compatibility choice

Alias-Data Plugin* Ordinary aliases resolve anchors in the current document* Alias-Data adds values from:* Inline configuration, files and the environment* Anchors from previous documents in the stream* It is opt-in: ordinary YAML behavior stays unchanged
Alias-Data PluginExternal values:$ vim -O alias-data.yaml alias-data-config.yaml$ SPEAKER=Ingy yaml --config=alias-data-config.yaml -y alias-data.yamlThe same configuration in go-yaml:$ make -C go-yaml cli$ SPEAKER=Ingy go-yaml --config=alias-data-config.yaml -y alias-data.yaml
